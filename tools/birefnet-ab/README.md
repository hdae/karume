# birefnet-ab

A blind A/B of BiRefNet's alpha-matte post-processing (ADR
[0125](../../docs/decisions/0125-birefnet-matte-postprocess.md)): the current path
(`float-bilinear` — antialiased bilinear on the floating-point sigmoid, then round) against the
BiRefNet_HR upstream's intent (`u8-pil-bicubic` — sigmoid, round to 8 bits, then Pillow's 8-bit
BICUBIC). Only BiRefNet_HR is compared; Lucida's upstream already is the current path.

Each image goes through the graph **once**; both procedures of
`packages/models/src/birefnet/matte.ts` are applied to the same logits. Loading and the family gates
are the pipeline's own (`loadBirefnetState` / `matteLogits`).

## Running

```sh
deno run -A tools/birefnet-ab/main.ts commands      # prints every command below, generates nothing
```

1. **Materials** (GPU): eight images generated by Anima from `corpus.ts` (prompts, seeds and sizes
   live there) — four at 2048×2048 (upscaled from the 1024² graph; the 2048² model's sigmoid serves
   as a pseudo ground truth) and four at 832×512 whose top and bottom 16 rows are cut off without
   interpolation (832×480, downscaled from 1024²). `commands` prints the `deno task demo:anima` lines;
   the images land in `outputs/examples/karume-anima/`.
2. **Pairs** (GPU): `deno run -A tools/birefnet-ab/main.ts run --out outputs/birefnet-ab/<date>`.
   It loads the 1024² model for all images, then the 2048² model for the 2048² images only — one
   session at a time.
3. **Cross-check** (CPU): `cd tools/export-recipes && uv run --group birefnet python -m
   birefnet.matte_ab_check ../../outputs/birefnet-ab/<date>/work` recomputes both procedures with the
   upstream functions that build the golden fixture and fails on anything outside its contract.

A dry run on any PNG written by `encodePng`: `run --image <png> [--crop <left>,<top>,<width>,<height>]
--out <dir>`.

## Output (under `--out` only)

- `blind/` — what the reviewer sees: `pair-<n>-{checker,black,white}.png` (A on the left, B on the
  right), `pair-<n>-zoom.png` (the 64×64 window where the two differ most, ×8, over the three
  backgrounds) and `answer-sheet.md` (A / same / B).
- `key/` — opened after answering: `mapping.json` (which procedure is A; reproducible from the seed)
  and `metrics.md` / `metrics.json` (recorded only, not used for the decision): the kernel column
  (the two procedures' difference inside the contour band) and, for 2048² images, SAD / MSE /
  gradient error against the pseudo ground truth.
- `work/` — logits (the graph output as is) and the 8-bit alpha of each procedure, for the
  cross-check.

The decision rule is fixed before looking (ADR 0125): the current path stays only if at least five
pairs favour it and none favours the upstream; otherwise the upstream procedure is adopted.
