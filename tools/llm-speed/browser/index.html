同じChromeで karume と Transformers.js を順番に計測します。

固定の英語・日本語入力から最大64トークンを生成。初回 → 暖機1回 → 本計測3回。TTFTは最初のトークンまでの時間、decodeはそれ以降の生成速度です。モデル取得・読み込み時間は別計測です。

通常版ONNXはq4f16、QAT ONNXはq2f16。karumeはf32演算です。配布重み・量子化・KVキャッシュの構成も異なるため、エンジン単独の性能差ではありません。
