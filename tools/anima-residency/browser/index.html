Anima · DiT 常駐のブラウザ確認

pipeline は residency: "transformer" で 1 度だけ組み、全ての generate で使い回します。generate ごとの常駐指定は下の選択肢で変えます。ダミーバッファは pipeline と同じ GPU device に確保します。

quant と「GPU 時間を採る」は GPU を取るとき（最初の generate か「VRAM を埋める」）に確定します。切り替えるには「pipeline を破棄」を押してから選び直してください。GPU 時間を採ると 1 dispatch = 1 pass に開くので、所要（壁時計）は採らないときと比べられません。Chrome は WebGPU Developer Features（chrome://flags/#enable-webgpu-developer-features）を有効にしない限り timestamp を 100 µs 単位に丸めます。
