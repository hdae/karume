# w4 fake-quant sweep — MiniCPM5-1B（ADR 0069 Phase 0・2026-08-18）

> **性格**: 時点スナップショット（2026-08-18 実測）。ADR
> [0069](../decisions/0069-packed-w4-storage.md) 決定 6 の Phase 0 — 既定 group_size と
> 裁定 B（zero-point 欄なし）の実測根拠。台本 =
> `tools/export-recipes/minicpm5/sweep_w4.py`（コミット `d88fc14`）・環境 = torch 2.13.0+cpu /
> transformers 5.14.1 / AMD Ryzen 5 5600（12 threads）。runtime 非接触（全て torch 側の
> fake-quant）。

## §1 方法

- 量子化対象 = 全 `nn.Linear` の weight 169 本（24 層 × q/k/v/o/gate/up/down + `lm_head` —
  `tie_word_embeddings: false`）。bias / norm / embedding は触らない。
- 量子化式は ADR 0069 決定 3 のとおり（group 軸 = in 軸・15 準位）。非対称列は zero-point を
  **丸めも格納もしない連続値**で使う — 「zero_point 欄を足したとき届きうる品質の上界」で
  あって格納可能形ではない。
- 期待列 = 波 E の greedy 資産（margin 門 1e-2 通過の 3 ケース: capital-en T=6 /
  context-en T=87 / context-ja T=61・各 K=16）。測定 3 列 = ①族別 weight 相対 RMSE
  ②teacher-forced（期待列上の 16 位置の top-1 一致数 + NLL 平均 — 発散しても位置が
  ずれない比較列）③自由走行 greedy が期待列と一致し続けた接頭辞長。
- baseline（f32 のまま）は teacher / 自由走行とも **16/16 全ケース一致**（sanity 門通過 —
  ハーネス・期待列・模型の対応が健全）。全 8 構成の実走は約 100 秒。

## §3 所見

1. **w4 RTN はこの 1B checkpoint で明確に劣化する**。teacher-forced 一致は全構成で
   31〜37/48、自由走行はほぼ全構成が早期に期待列から離れる（相対的に持つのは g32-sym の
   23/48 のみ）。「格納だけ w4・計算 f32」でも品質は f32 と同格ではない — w4 の採否・既定は
   品質と引き換えの選択であることが数値で立った。
2. **裁定 B（zero-point 欄なし）を支持**: 連続 zero-point の**上界**ですら、weight 空間の
   改善（族平均で同 group の対称比 −11〜−15%）がモデル級の品質に乗らない（teacher で g32 は
   逆転・自由走行は全 group で対称以下・NLL の最良差も僅少）。しかも weight 空間の同幅の
   改善は group を 1 段細かくするだけで得られる（g64-asym 族平均 0.0986 ≈ g32-sym 0.1001・
   g128-asym 0.1113 ≈ g64-sym 0.1127）— 品質つまみは group_size 1 本に集約でき、欄追加の
   根拠が立たない。
3. **group_size**: weight 相対 RMSE は 32 < 64 < 128 で単調。モデル級指標は noisy だが、
   自由走行の保持は g32-sym が明確に最良で、teacher / NLL でも g32/g64 が g128 に優る。
4. **lm_head の寄与は小さい**: g128-sym-blocks（lm_head 除外）は g128-sym 比で NLL 3.71 →
   3.43・teacher 31 → 32 の改善に留まる。lm_head を特別扱い（高 bit 化・除外）する強い根拠は
   この時点では無い。

## §4 限界

- 判定点は 3 ケース × 16 位置 = 48 点 + NLL のみで薄い。checkpoint も MiniCPM5-1B の 1 点 —
  w4 の劣化は小さいモデルほど大きい傾向が知られており、Gemma 4 E2B（波 H）では別途測る。
- RTN（round-to-nearest）のみ。AWQ / GPTQ 級の重み調整は測っていない（実需が立てば別 ADR）。
- 人間による生成文の読み味レビューは未実施（ADR 0058 決定 5 の「品質 = 人間レビュー +
  助言的数値」の数値側だけがここにある）。
- 自由走行の「発散」は期待列との接頭辞比較であり、発散後の文が壊れていることを直接は
  意味しない（greedy の別経路に入るだけ）。位置が揃う比較は teacher-forced 列の側。
- Phase 1（実装）の検収方法論はこの結果に依存しない: karume の門は「fake-quant 済み重みで
  採った参照と GPU のビット一致 / tolerance」であり、品質劣化は門の緑赤に混ざらない
  （ADR 0006）。
