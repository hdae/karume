## major（1 件・holds）

- **L1-01 — safe-softmax ガードの不活性証明が lifted 定数の -inf を見落とす**:
  `_can_be_neg_inf` が placeholder（torch.export が持ち上げる buffer / parameter / 定数）を
  無条件に有限視していたため、`register_buffer` した -inf マスクが「no-neg-inf」と誤証明され
  ガードが除去 → 出力が 0 から NaN へ黙って変わる。レンズが**実行で再現**（該当 stats +
  NaN 出力）しており、敵対検証レッグは省略して holds と裁定（実行済み証拠 + メインの機構
  確認）。Anima の 4 ターゲット自体はマスクをグラフ内生成するため未被弾。**根治**（波F）:
  `normalize_graph` を ExportedProgram 受けに変え、placeholder を `state_dict` / `constants`
  の実値で判定（user_inputs のみ有限仮定・実値不明は fail loudly 側）。故障注入で旧挙動へ
  戻すと新テストのみ赤になることを実証。

## レビューが確認した「問題なし」の要点（再調査の抑止）

- 波1 カーネル（conv2d / rms_norm / clamp_min）は L2 が添字・barrier・params・binding・
  縮退・full-write を手計算検算まで実施し**指摘ゼロ**。
- ホストグルーのビット一致要求は妥当（f64 中間 → f32 の二重丸めは p=53 ≥ 2·24+2 で無害、
  numpy linspace / NEP50 / torch f32 逐次と `Math.fround` 逐次が演算単位で対応）。
- L3 は「恒真化の穴は見つからなかった」— 契約 3 点同期・golden 双方向被覆・WGSL
  スナップショット双方向突合・故障注入ケースの検出力を確認済み。
