# Index of quantization methods (quantization)

> The canonical source is the pointer in each cell. This page is an index — it does not copy numbers or semantics; it only holds where to read to settle them.
> Term definitions: [glossary](glossary.md); adoption of performance candidates: [perf-ledger](perf-ledger.md);
> by-design constraints: [limitations](limitations.md); work order: [backlog](backlog.md) — each of these is the canonical source.
> Status vocabulary: `product default` / `optional` (selectable as a preset or an execution option) / `experimental` (family-only) /
> `declared only` (accepted, but there is no execution path) / `on hold` (measurement only; no storage path) / `rejected` (kept as a record).

## Table 1 — Storage dtypes (the form baked into the assets)

Canonical source = the codec ledger (`CODEC_LEDGER` in `packages/runtime/src/format/container/codecs.ts`;
[container-v1](container-v1.md) §6.3) and `allowedLayouts` of the binding layer, which holds the mapping to semantic dtypes
(`packages/runtime/src/format/container/bind.ts`; the "values and types" section of [ir-v2](ir-v2.md)).
The storage dtypes in the table are the names of the codec's decode paths; the registered names map as `int8-sym` → `i8`, `int4-sym-g` → `i4`,
`int4-sym-g-f16` → `i4f16`, `int2-off` / `ternary` → `i2`. Since ADR 0006 the backbone is "semantics are f32; only the storage is compressed", and
`i32` is the only exception (raw int32 of symbol-dependent constants).

### Table 2-b — Contract classes of the options that change numbers (ADR [0147](decisions/0147-numerics-and-kernel-adoption.md) decision 2)

E = atol=0 against the TS mirror, or u32 equality with the unfused plan for a plan transformation / C = atol=0 against host rounding + the existing f32 kernel / R = only the summation order differs (the f64 band stays the op band of the reference path) / Q = a band wider than the reference op band, from an error model (member: `attentionScoreStorage: "none"`). Four points = ① the band against f64 ② the A/B band against the reference path ③ exact checks of structural guarantees ④ a recorded fault injection — MUST for every new R / Q option; the existing ones keep their admission under the grace clause, with the missing points filed in the backlog. This table is the living copy of ADR 0147 decision 2's classification (as of 2026-11-09) and is kept current with every new option.
