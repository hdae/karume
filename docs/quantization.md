# Index of quantization methods (quantization)

> The canonical source is the pointer in each cell. This page is an index — it does not copy numbers or semantics; it only holds where to read to settle them.
> Term definitions: [glossary](glossary.md); adoption of performance candidates: [perf-ledger](perf-ledger.md);
> by-design constraints: [limitations](limitations.md); work order: [backlog](backlog.md) — each of these is the canonical source.
> Status vocabulary: `product default` / `optional` (selectable as a preset or an execution option) / `experimental` (family-only) /
> `declared only` (accepted, but there is no execution path) / `on hold` (measurement only; no storage path) / `rejected` (kept as a record).

## Table 1 — Storage dtypes (the form baked into the assets)

Canonical source = the codec ledger (`CODEC_LEDGER` in `packages/runtime/src/format/container/codecs.ts`;
[container-v1](container-v1.md) §6.3) and `allowedLayouts` of the binding layer, which holds the mapping to semantic dtypes
(`packages/runtime/src/format/container/bind.ts`; the "values and types" section of [ir-v2](ir-v2.md)).
The storage dtypes in the table are the names of the codec's decode paths; the registered names map as `int8-sym` → `i8`, `int4-sym-g` → `i4`,
`int2-off` / `ternary` → `i2`. Since ADR 0006 the backbone is "semantics are f32; only the storage is compressed", and
`i32` is the only exception (raw int32 of symbol-dependent constants).

### Table 2-b — Contract classes of the options that change numbers (ADR [0110](decisions/0110-practical-tier-numerics-contract.md) decisions 2 and 9)

E = atol=0 against the TS mirror / C = atol=0 against host rounding + the existing f32 kernel / R = only the summation order differs (the f64 band stays the op band of the reference path) / Q = a band wider than the reference (approximation; none admitted).

| Option (value)                                                         | Class | Notes                                                    |
| ---------------------------------------------------------------------- | ----- | -------------------------------------------------------- |
| `linearCompute: "a8"`                                                  | E     | dp4a vs emulation is also atol=0                         |
| `convCompute: "a8"`                                                    | E     | one fma per tap in ascending tap order; dp4a vs emulation atol=0 |
| `attentionCompute: "a8"`                                               | E     | statistical check only for the qP generation of ③ PV     |
| `linearCompute` / `attentionCompute: "f16"`                            | C     | atol=0 against the f32 variant with inputs rounded to f16 |
| `attentionScoreStorage: "f16"`                                         | C     | atol=0 against the f32 variant with S rounded on the host |
| `attentionScoreStorage: "none"`                                        | Q     | the P̃-lattice error model; all four points (ADR 0132)      |
| `stateAttentionReduce: "parallel"` / `"parallel-fused"`                | R     | all four points present                                  |
| `linearGemvReduce: "parallel"`                                         | R     | no fault-injection record yet (grace clause)             |
| `rmsNormReduce` / `linearGemvReduce` subgroup32                        | R     | no A/B band and no fault injection yet (grace clause)    |
| `fuseRmsNormAdd` / `fuseLinearStaticQuantize` / `packedStaticQuantize` | E     | u32 equality with the unfused path                       |
